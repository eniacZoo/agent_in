# 文档翻译（pdf/docx/txt/md → 中文）

人读、人改。模型用 `read_file` 打开本文件，再用现有工具做完。不要调用不存在的 skill 工具。
源文件是 PDF 时先读 [pdf.md](pdf.md)，要出 Word 版再读 [docx.md](docx.md)。长脚本 `timeout` 用 120。

## 何时加载

用户要「翻译全文 / 另存一份翻译版 / 论文·大纲·说明书中文化」，且要保留排版、输出成可读文件。

## 步骤

1. **抽文本**：写 `temp/xx_extract.py`，pypdf 逐页抽，存成 `temp/xx_text.json`。控制台只打印
   `pages: N` 与每页字符数。**不要把全文打进对话**。扫描件/无文字页：导出图再 `view_image`，
   不要假装抽到了字。
2. **看原文块结构**：从 json 里读**小块**（标题、模块名、列表项）确认层级，再决定译文结构。
   需要原样式时用 `docx.Document(src)` 遍历段落；PDF 没有样式就按语义重建（标题/小标题/正文/列表）。
3. **翻译**：自己在脚本里写译文常量（标题、导语、各级标题、正文、脚注），不要逐段拼字符串。
   术语要求：
   - 首次出现的专有名词、协议、人名、产品名：`中文（English 原名）`，之后只用中文。
   - 模块/章节标题：`N. 中文译名（English Original Title）`，方便对照。
   - 代码、变量、文件名、URL、数字单位原样保留；不要意译专有缩写（RAG、A2A、MCP、Embeddings）。
   - 译完加一句落款说明：`注：本文件为《原文文件名》英文原版的中文翻译版本，模块名保留英文原名以便对照。原文共 N 页。`
4. **生成文件**：python-docx 写 `temp/xx_zh.docx` → Word COM 另存 PDF。字体必须显式设
   `w:eastAsia`，否则中文变方框。

```python
st = doc.styles['Normal']; st.font.name='Times New Roman'; st.font.size=Pt(10.5)
st.element.rPr.rFonts.set(qn('w:eastAsia'), '微软雅黑')
def setfont(run, name='微软雅黑'):
    run.font.name = name; run._element.rPr.rFonts.set(qn('w:eastAsia'), name)

import win32com.client as w
app = w.Dispatch('Word.Application'); app.Visible = False
try:
    d = app.Documents.Open(tmp_docx)
    try:    d.SaveAs(out_pdf, FileFormat=17)          # 17 = wdFormatPDF
    except Exception: d.ExportAsFixedFormat(out_pdf, 17)
    d.Close(False)
finally:
    app.Quit()
```

5. **产物命名/落盘**：与原文同目录，`<原文件名>_中文翻译.pdf`（要 Word 版再给一份 `.docx`）。
   写工作目录外先跟用户确认。`temp/` 里的中间 docx 可留可删。

## 校验

- `read_file` 打开产物：页数、标题、模块/章节数与原文一致；抽查首尾段落。
- 用 pypdf 数关键元素：`re.findall(r'\n\s*(\d+)\. ', t)` 对模块数、`'注：' in t` 对落款。
- 原文文字能对上的都要译到，缺的写「原文没有」。原始文件不动。
- 通过即停：不要再截图或重复校验同一结论。

## 坑

- pypdf 抽 PDF 常把每个词单独成行（`"AI\n \nRed\n \nTeamer"`）——先合并空白再判断结构，
  别当成换行排版。
- 老版 Office（如 Word 12）COM 对中文路径/长路径更稳的写法是：先用绝对英文临时路径存 docx，
  再 SaveAs 到目标路径。
- 无 Word/无 LibreOffice 时如实说明，退回只交付 `.docx`；禁止 pip/npm 安装。
- 控制台可能是 GBK：脚本里读盘写盘统一 utf-8，输出别打大段中文。
