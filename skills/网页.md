# 网页

人读、人改。模型用 `read_file` 打开本文件，再用现有 5 个工具做完。不要调用不存在的 skill 工具。

## 何时加载

http/https URL、列表页摘要、抓一篇静态页。

## 读

1. HTML 和一次性脚本只写 `{工作目录}/temp/`。禁止写仓库根。
2. 标准库或 `curl.exe` 拉取，超时约 20s，带普通浏览器 User-Agent。摘要写入 `temp/task_notes.md`。
3. 列表页只要前 N 条：只解析列表，不要默认再抓每条详情。用户明确要深读某条再抓。
4. JS 重度页（几乎无 HTML 文本）：说明无 Chromium，不要装 Playwright 浏览器。

## 改

写一份 `temp/*.py` 拉页+解析。不要在根目录堆 `parse_*.py` 改正则。

## 校验

标题/链接能对上页面。磁盘上新文件只在 `temp/`。

## 坑

禁止 pip/conda/npm install。清缓存用 `Remove-Item -Recurse -Force temp\某文件`。工具表仍是 5 个。
