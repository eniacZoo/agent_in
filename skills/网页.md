# 网页

人读、人改。模型用 `read_file` 打开本文件，再用现有工具做完。不要调用不存在的 skill 工具。

## 何时加载

http/https URL、列表页摘要、抓一篇静态页。

## 读

1. HTML 和一次性脚本只写任务临时目录 task_temp（`temp/tasks/<会话>/`）。禁止写仓库根，探查输出也不要写进交付目录。
2. 标准库或 `curl.exe` 拉取，超时约 20s，带普通浏览器 User-Agent。摘要写入 task_temp/task_notes.md。短脚本用 python 工具，不要用 shell 里的 `python -c`。
3. 列表页只要前 N 条：只解析列表，不要默认再抓每条详情。用户明确要深读某条再抓。
4. JS 重度页：不要安装浏览器。验收自己做的页面时用 skills/网页验收.md（Playwright 驱动系统自带的 Edge，channel=msedge）。抓别人的登录页不在本流程里。

## 改

用 python 工具写一段拉页+解析。不要在根目录或交付目录堆 `parse_*.py`。

## 校验

标题/链接能对上页面。磁盘上新文件只在 `temp/`。

## 坑

禁止 pip/conda/npm install。临时文件放 task_temp，任务结束会被清理；要留的笔记写 task_notes.md。
