# 网页验收

人读、人改。模型用 `read_file` 打开本文件。适用于：自己做的本地页面，声称能打开之前必须用浏览器看过。

不要 `pip install`，不要 `playwright install`。不要自己写 Playwright，不要改 vendor。

## 步骤

1. 用 shell 启动服务，`background=true`。确认端口已监听再往下走。
2. 只调 `preview_page`，参数 `url` 换成实际地址。工具会用系统 Edge 在 1440×900 和 390×844 下截图，图写在 task_temp。
3. 看工具返回的标题、控制台错误，以及附上的截图（没有视觉能力时看正文摘要）。布局溢出、文字挡住、空表、控制台报错，都要改。
4. 有问题就改页面，再调一次 `preview_page`。两张图都正常，才能说页面可用。
5. 结束前用 job 停掉自己起的验收用进程。用户要长期开着的服务，写成 start 脚本，不要只留一个后台 job。

Edge 启动失败，或页面打不开，报告原因并停。不要另写验收脚本。
