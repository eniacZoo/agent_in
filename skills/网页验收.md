# 网页验收

人读、人改。模型用 `read_file` 打开本文件。适用于：自己做的本地页面，声称能打开之前必须用浏览器看过。

不要 `pip install`，不要 `playwright install`。vendor 里已有 Playwright，用系统自带的 Edge。

## 步骤

1. 用 shell 启动服务，`background=true`。确认端口已监听再往下走。
2. 用 python 工具跑下面的检查（把 URL 换成实际地址）。截图写到 task_temp，不要写进交付目录。
3. 对两张截图分别 `view_image`。看布局是否溢出、文字是否挡住、空表、控制台报错。
4. 有问题就改，再跑一遍。两张图都正常，才能说页面可用。
5. 结束前用 job 停掉自己起的验收用进程。用户要长期开着的服务，写成 start 脚本，不要只留一个后台 job。

```python
import os
from playwright.sync_api import sync_playwright

url = "http://127.0.0.1:8000/"
out = os.environ.get("TASK_TEMP") or "temp"
shots = []
errors = []
with sync_playwright() as p:
    browser = p.chromium.launch(channel="msedge", headless=True)
    page = browser.new_page()
    page.on("pageerror", lambda e: errors.append(str(e)))
    page.on("console", lambda m: errors.append(m.text) if m.type == "error" else None)
    for w, h, name in ((1440, 900, "desktop"), (390, 844, "mobile")):
        page.set_viewport_size({"width": w, "height": h})
        page.goto(url, wait_until="domcontentloaded")
        path = os.path.join(out, name + ".png")
        page.screenshot(path=path, full_page=True)
        shots.append(path)
    browser.close()
print("shots", shots)
print("console_errors", errors[:20])
```

python 工具的工作目录就是任务目录时，把 `out` 设成 task_temp 的绝对路径。Edge 找不到就报告「本机没有 Edge」，不要改去装 Chromium。
