# Excel（.xlsx）

人读、人改。模型用 `read_file` 打开本文件，再用现有 5 个工具做完。不要调用不存在的 skill 工具。长脚本 `timeout` 用 120。

## 何时加载

用户要打开、读取、修改、扩表、另存 `.xlsx` / `.xlsm`。

## 读

1. 确认文件存在。
2. 用 vendor 的 openpyxl 探结构，**摘要写入** `{工作目录}/temp/task_notes.md`（sheet 名、表头映射、数据起始行、行数/列数、关键合并、样例行）。不要把整表打进对话。
3. 行级数据超过约 50 行且要按键聚合时，可建 `temp/*.db`（SQLite），用完可删。小表不必建库。

## 改

列映射一旦清楚，立刻写**一份** `temp/*.py` 再跑。报错只改脚本，不要推倒用一串 `python -c`。

- 禁止 pip。PYTHONPATH 已含 vendor。
- 不要解 XML。
- 改表：复制样式用 `copy.copy(cell.font/fill/...)`；公式按行号平移时，先改 SUM 区间再改同行引用，避免把 SUM 下标二次替换。
- 扩行后按用户要求合并列；底色、红字跟原街道/原单元格。
- 产物另存到用户指定路径；过程文件只进 temp/。

## 校验

- 用户给的示例行（如「第 3 行某某网点」）
- 行数/网点数（注意合计「不含」的例外行）
- 合并范围、小计 SUM 不含小计自身
- 底色与红字抽样

## 坑

- `data_only=True` 才能拿到公式缓存值；没有缓存就保留公式。
- openpyxl theme 颜色用 copy 样式，不要自己拼 RGB。
- 工具表仍是 5 个。
