# 读网页

人读、人改。模型用 `read_file` 打开本文件，再用现有 5 个工具做完。不要调用不存在的 skill 工具。

## 输入

- http/https URL
- 列表页只要前 N 条时：只解析列表，不要默认再抓每条详情

## 步骤

1. HTML 和一次性脚本只写 `{工作目录}/temp/`（没有就建）。禁止写仓库根目录。
2. 用标准库拉取（已有 `curl.exe` 也行），超时约 20s，带普通浏览器 User-Agent：

```
python -c "import urllib.request; u='URL'; req=urllib.request.Request(u, headers={'User-Agent':'Mozilla/5.0'}); open(r'temp/page.html','wb').write(urllib.request.urlopen(req, timeout=20).read())"
```

3. 同一段 Python 抽出标题/链接（或可见正文）打印到 stdout，直接总结。
4. 用户明确要深读某条再抓该 URL。JS 重度页（几乎无 HTML 文本）说明：无浏览器，Playwright 未装 Chromium。

## 坑

- **禁止** pip/conda/npm install。
- 不要为一条列表任务写一堆 `parse_*.py` 在根目录改正则。
- 不要 `Remove-Item -Recurse` 仓库根；清缓存用 `Remove-Item -Recurse -Force temp\某文件`。

## 如何验收

- 标题/链接能对上页面。
- 磁盘上新文件只在 `temp/`。
- 工具表仍是 5 个。
