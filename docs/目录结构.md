# agent_in 3.0 目录结构

产品版本 **3.0**。本文件描述当前仓库分层；运行期目录（`logs/`、`sessions/`、`usage/`、`temp/`）不进 git，以本机为准。

`README.md` 留在根目录。Changelog、设计计划与本文件在 `docs/`。开发期验收脚本在 `tests/`。

## 目录树

```text
agent_in/
│
├── agent.py                 主入口：交互 / 单次任务 / 工作目录 / 多模态
├── loop.py                  Agent 核心循环（发消息 → 工具 → 回填）
├── commands.py              斜杠命令表（/status /use /ls 等）
├── llm.py                   LLM 客户端：SSE、Function Calling、Reasoning
├── tools.py                 7 工具：read_file/write_file/edit/shell/view_image/glob/grep
├── ui.py                    终端 UI：渲染、spinner、状态、版本号
│
├── context.py               上下文截断 / 压缩
├── tool_guard.py            工具调用守卫
├── approval.py              危险操作审批（强确认）
├── audit.py                 审计日志 JSONL
├── rate_limiter.py          按 provider:model 限流
├── retry.py                 可重试错误 + 指数退避
├── capability.py            模型能力探测（tool_call / vision / 上下文）
├── heartbeat.py             API 端到端探测
├── debug.py                 /debug 长链路旁路记录
│
├── session.py               会话持久化 → sessions/
├── memory_manager.py        长期记忆 → memory/MEMORY.md
├── usage.py                 Token / 成本 → usage/
│
├── skill_manager.py         加载 skills/
├── skill_scanner.py         技能文件扫描（零依赖）
├── vision.py                视觉输入：格式与大小
│
├── config.py                配置：CLI > agent_config.json > 环境变量 > 默认
├── providers.py             Provider 注册表
├── logger.py                按天日志 → logs/
├── chat_3.8.py              独立 OpenAI 兼容对话客户端
│
├── README.md                项目说明（留根目录）
├── agent_config.example.json
├── .gitignore
│
├── docs/                    设计文档与计划
│   ├── CHANGELOG.md         版本记录
│   ├── 目录结构.md          本文件
│   ├── test.md              早期 llm.py 笔记
│   ├── plan.md              v1.x
│   ├── plan2.0.md … plan23.0.md
│   └── plan_office_2.0.md   Office 场景专项
│
├── tests/                   开发期验收（按 plan 增量写下）
│   ├── _test_plan7.py … _test_plan23.py
│   ├── _test_pty3.py        PTY / 审批输入（Unix）
│   ├── _test_spinner_pause.py
│   └── _test_vision.py
│
├── skills/                  markdown 流程 + 脚本 skill
│   ├── xlsx.md / docx.md / pptx.md / pdf.md / 网页.md / 翻译.md
│   ├── 周报转docx.md
│   ├── 读*.md               旧名，指向上面的流程
│   └── read_xlsx/           脚本 skill（skill.json + main.py）
│
├── vendor/                  离线办公套件（约 208MB，见 vendor/README.md）
├── rules/                   危险 Shell、敏感路径
│
├── logs/                    运行日志（gitignore）
├── memory/                  MEMORY.md（gitignore）
├── sessions/                会话快照（gitignore）
├── usage/                   用量（gitignore）
└── temp/                    可删沙箱（gitignore）
```

## 模块分层

| 层 | 模块 | 职责 |
|---|---|---|
| 入口 | `agent.py`、`chat_3.8.py` | CLI 主循环 / 独立对话客户端 |
| 循环与命令 | `loop.py`、`commands.py` | 工具循环、斜杠命令 |
| LLM | `llm.py`、`providers.py`、`capability.py`、`retry.py`、`rate_limiter.py`、`heartbeat.py` | 请求、能力、重试、限流、探活 |
| 工具与安全 | `tools.py`、`tool_guard.py`、`approval.py`、`audit.py`、`rules/` | 工具执行、拦截与审计 |
| 上下文与记忆 | `context.py`、`session.py`、`memory_manager.py` | 上下文、会话、长期记忆 |
| 技能与视觉 | `skill_manager.py`、`skill_scanner.py`、`vision.py` | 技能加载、图像 |
| 基础设施 | `config.py`、`logger.py`、`usage.py`、`ui.py`、`debug.py` | 配置、日志、成本、终端、调试 |

## 备注

- 密钥只放本机 `agent_config.json`，不进版本库。
- `tests/` 是开发时跟着各 `plan*.md` 写的验收脚本，不是 pytest 工程。从仓库根目录跑：`python tests/_test_plan22.py`。
- `docs/plan*.md` 是迭代设计稿，不是当前实现的规格；以源码为准。
- `__pycache__/`、`_tmp_*.jpg`、`tmp_pptx_img/` 可删。
