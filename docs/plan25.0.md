# agent_in v25.0 — 产出要看文件是否真变，列循环允许有上界

> 前置：plan24。无产出刹车如果把「命令里提到了已有 xlsx」当成写出，探查也会被记成进展。

## 做了什么

1. **产出**  
   shell 前后对命令涉及的路径做快照。已有文件时间没变，不算写出。新文件或 mtime 变了，才算。

2. **列循环**  
   `range(...max_column)` 无上界仍拒绝。`min(ws.max_column, N)` 或 `min(N, ws.max_column)` 且 N ≤ 80 放行。

3. **重复提醒**  
   同一调用第二次才提醒。上一次失败，或脚本内容变了，不报重复。

## 验收

- [x] 只提到已有 xlsx 不算产出；新建或改写才算
- [x] 无上界 `max_column` 拒绝；`min(..., 32)` 放行；上界 100 仍拒绝
- [x] 脚本哈希变化或上次失败时不告重复
